## 1. What we test

When a planted feature's rule exists **only in a document**, does Rogue One build that feature once the document is reachable through its knowledge channel? We swap only the backend behind the shared search summariser W (all three roles): Off, Parametric (no retrieval), Local-correct (the document plus distractors) or Local-wrong (the document with a wrong formula). P7's rule is fictional and is designed so that it can be neither web-searched nor guessed; A14-T3 and the A14-T6 leak canary check this before any A14 run. C4a is the paper's only confirmatory test of the knowledge *channel* and its positive control (C4b, A15, is the other knowledge contrast in the Holm family, but it tests column names on P6a/P6b, not the channel); it is an existence proof on one task we built, not a rate.

**Instrument `synp_p7`** (E8a; proposed classification, `tasks/classification/synp_p7/`): n = 2,000, p ≈ 20–30; φ = fictional documented composite (ratio × threshold with an unguessable constant), headroom ≥ 0.06 balanced accuracy. `context_and_goal` names the fictional domain term the document defines, never the formula. **φ_wrong**: pre-registered, |ρ(φ_wrong, φ)| < 0.5 on the training rows, and ≈ 0 headroom on CPU, operationalised (proposed) as XGB(raw + φ_wrong) − XGB(raw) < 0.01 balanced accuracy with E8a's headroom procedure. The machine-readable φ, φ_wrong and detector definitions live only in `~/rogueone-synp-meta/`, which is never mounted into an agent container; the formulas reach agents only as document text, in the corpus mounted for `kb_local_*` rows. **P7 policy:** P7 runs only in A05, A02, the A08 CPU screen, the A09 oracle and A14.

**Metrics (R13; definition as 01 §4.6).** `rec_sel` (primary): an active, non-fallback feature present in the iteration that inner CV selects has |Spearman| ≥ 0.95 with φ on the fold's training rows, or normalised MI ≥ 0.9 (P7 is in the rule/threshold family, so the NMI criterion applies; no credit for P7's ratio component alone). Raw columns and single-column monotone transforms never count. Computed by E8a's `scripts/agent2027/analysis/recovery_detector.py`; unit = fold-episode. `rec_any` = the same criterion at any iteration of the fold. Also logged: `iter_first_rec`, `heldout_score`, `tok_compl_*`, `tok_search_<role>`, `serper_calls`, `fun_*`. ITT: a failed or capped run contributes 5 episodes with `rec_sel = rec_any = 0`.

## 3. Hypotheses and interpretation (all hypotheses)

| | Hoped | Sentence it allows |
|---|---|---|
| **H1 (C4a)** | Off ≈ Parametric ≈ 0–10%; Local-correct ≥ 60% (e.g. 20/30 vs 2/30), near the A09 oracle | *"With the right document in a swappable local corpus, recovery of an otherwise unreachable feature rose from a% to b% (raw p = x; Holm-adjusted p < 0.05); the same consultation without the document did not help."* + "existence proof on one task we built". |
| **H2 (secondary, outside Holm)** | Local-correct > Parametric and Local-correct > Local-wrong on seeds {42, 4, 5} (15 vs 15 episodes; same exact stratified test as C4a, two-sided, uncorrected α = 0.05) | Required before writing "the document's content carried the feature". |
| **H3 (exploratory)** | φ_wrong adopted, pruned within ≤ 3 iterations, not re-proposed | *"A feature built from a wrong document was discarded after a median of k iterations."* Never "corrects wrong priors" (one task, exploratory). |

All counts below are `rec_sel` unless `rec_any` is named; thresholds marked "proposed" freeze in A14-T5. Because C4a is pre-registered, its raw p always enters the final Holm family once A14 has data (01 §4.7: contrasts are dropped only before data exist); the readings below change what the paper may *say*, not whether C4a is tested.
- **Null, both low** (Local-correct − Off not significant and Local-correct ≤ 6/30): G3 knowledge half fails. Locate the break (retrieval → summary → focus → implementation, A14-T15). A09 oracle `rec_sel` ≥ 2/5 on P7 → the break is upstream of implementation (retrieval or hand-off); ≤ 1/5 → "execution-bound" (§6). Drop the title word; knowledge becomes process metrics only (01 §6.1 G3), and C4 is worded as *"a pluggable, costed channel (backend swapped without changing the architecture; KT1-Off cost); in our probe it did not carry a documented rule into features"*.
- **Null, both high** (proposed: Off `rec_any` ≥ 4/30, i.e. above the hoped 0–10% band, and Local-correct − Off not significant): P7 is findable without the document; probe invalid, reported as a failed instrument; no knowledge sentence.
- **Neither pattern** (not significant, Local-correct > 6/30, Off `rec_any` < 4/30): "inconclusive"; G3 follows §6.
- **Opposite:** (a) Parametric `rec_any` ≥ 4/15 (proposed) → rule guessable; C4a is still reported with its Holm result, but labelled "failed control: not knowledge-only" and no knowledge sentence is written. (b) φ_wrong survives (proposed: `wrong_sel` ≥ 8/15 in Local-wrong, or re-proposed after pruning in ≥ half of the episodes with `wrong_any` = 1) → drop the wrong-prior clause; "a wrong source is a liability". (c) Local-correct `rec_any` high but `rec_sel` or `heldout_score` flat → bottleneck in selection/pruning. (d) Local-correct < Off (point estimate, any p) → the corpus distracts; report as a negative result. (e) φ_wrong never built (`wrong_any` ≤ 1/15) → H3 not evaluable; report that the wrong document was not acted on.

| 19/30 vs 6/30 | — | 0.0023 | yes |
| 18/30 vs 5/30 | — | 0.0019 | yes |

So C4a needs a gap of ≈ 30 pp when Off is at 0 and ≈ 40 pp when Off is at 20%, consistent with the breakdown's "about 30–40 pp", but the breakdown's example 18/30 vs 6/30 sits just above 0.005 under the stratified test. With 3 seeds (15 vs 15) C4a would need ≈ 12/15 vs 3/15 (stratified p = 0.0041). H2 (15 vs 15, α = 0.05) needs ≈ 5/15 vs 0/15 (p = 0.049) or 7/15 vs 1/15 (p = 0.038); 9/15 vs 3/15 fails (p = 0.071). The run-level 6-vs-6 permutation (unpaired) has minimum two-sided p = 2/C(12,6) = 2/924 = 0.0022, so it can clear 0.005 only when the two arms separate completely.
