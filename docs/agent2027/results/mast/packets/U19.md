1. **axial_stress = axial_load_kn / cross_section_cm2** (approximate axial stress).

This focus introduces concrete new features without removing existing ones, satisfying the additive requirement.

### Risks and uncertainties  
- **Multicollinearity:** Many engineered features (VIF > 100) are highly collinear (e.g., axial_stress, slenderness_ratio, inverse_slenderness, buckling_factor). While the model (XGBoost) can tolerate collinearity, it may inflate variance and obscure true causal relationships.  
- **Over‑fitting to engineered ratios:** The strongest engineered features dominate; if the test set distribution differs (e.g., different member geometries), reliance on these ratios could reduce robustness.  
- **Low‑importance categorical one‑hots:** Several one‑hot flags contribute virtually nothing; retaining them adds noise and computational cost.
