**Focus (exploratory)** – Add a compact set of time‑cycle, rate‑change and physics‑based interaction features, plus smoothed target encodings for the three categorical columns.

1. **Cyclical time encodings** (additive)  
   - `hour_of_day = hours_since_start % 24`  
   - `sin_hour = sin(2 π * hour_of_day / 24)`

   - `dust_humidity = dust_concentration_mg_m3 * relative_humidity_pct`

4. **Maintenance‑age ratio** (additive)

## ⚡ Summary  

- **Clear winners** – The cyclic time encodings (`sin_hour`, `cos_hour`, `hour_of_day`) together with several dust‑related interaction ratios (`dust_per_sensor_age_ratio`, `dust_sensor_age_interaction`, `dust5min_humidity_interaction`, `dust_hours_ratio`) show the strongest predictive signals (high **mutual information** ≈ 0.03–0.05, **mean‑abs‑SHAP** ≥ 0.15, non‑zero **PFI**).  
- **Moderate contributors** – `supply_voltage_v`, `noise_level_db`, `ambient_temperature_c`, `vibration_rms_mm_s`, `line_pressure_kpa` and the basic sensor‑age / operating‑hours features have modest MI (0.005–0.02) and SHAP (0.07–0.13).  
- **Potentially problematic** – A large set of features have **inflated VIFs (≈ 1e12)**, indicating perfect multicollinearity (mostly one‑hot encoded categorical variables and many derived ratios). This can destabilise the model and hide the true contribution of individual columns.  
- **Low‑value / noisy** – Features with near‑zero MI, zero SHAP and/or high **noise‑sensitivity** (e.g., `dust_humidity`, `dust_temperature`, `operator_shift_target_enc_smooth`, `dust_concentration_5min_mean`) add little predictive power and are prime pruning candidates.  

> **Actionable insight for the Planner:** Focus the next hypothesis generation on refining the temporal encodings (e.g., adding lagged sin/cos terms) and on the dust‑sensor‑age interaction family, while consolidating or dropping highly collinear categorical encodings.
