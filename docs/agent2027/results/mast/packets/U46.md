## Assessment Report – Feature Set (Step 3)

### Summary
The current feature set is dominated by a handful of **high‑signal, non‑linear interactions** that combine the core physics predictors (axial stress, slenderness ratio, vibration‑load interaction) with temperature‑adjusted and log‑scaled environmental variables.  

- **Top performers**:  
  - `axial_stress_adj_x_slenderness` (MI = 0.985, PFI = 1.108, VIF ≈ 306) – the strongest predictor overall.  
  - `axial_stress_adj_x_slenderness_sq` (MI = 0.800, PFI = 0.027, VIF ≈ 110) – a powerful quadratic interaction.  
  - `axial_stress_adj_x_log_humidity` and `axial_stress_adj_x_log_humidity_x_log_temperature` retain solid MI (0.421 / 0.383) and respectable PFI (0.00064 / 0.00105) despite very high VIF, indicating useful signal for tree‑based models.  

- **Core physics features** (`axial_stress`, `slenderness_ratio`, `vibration_load_interaction`) still carry predictive weight (MI ≈ 0.44‑0.31) but suffer from **extreme multicollinearity** (VIF > 10⁶ for axial_stress, > 300 for slenderness).  

- **Many added transforms** (log‑humidity, log‑temperature, cubic axial stress, square‑root vibration) show **low MI** (< 0.07) and **negligible PFI**, often with **very high VIF** (hundreds to thousands).  

Overall, the model’s predictive power is concentrated in a compact core of engineered interactions; the majority of other engineered attributes add little information and introduce severe collinearity.
