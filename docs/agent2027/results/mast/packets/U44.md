  RESULT: **Handling Multicollinearity in Gradient‑Boosting Models – A Feature‑Engineering Checklist**

Gradient‑boosting learners (XGBoost, LightGBM, CatBoost, HistGradientBoosting, etc.) are tree‑based.  
Because a split is made on a **single feature at a time**, the algorithm will usually pick the “best” among a set of highly correlated predictors and ignore the others. That means multicollinearity rarely hurts pure predictive performance, but it can:

* inflate the importance of one correlated variable while suppressing the others (making model‑explanations unstable)  
* cause the model to be sensitive to small changes in the data‑distribution (e.g., when the correlation structure shifts)

### Final focus handed to the CODER

**Focus (exploitative):** Introduce a set of additive, orthogonalized physics‑inspired and target‑encoded features to strengthen the core signal while mitigating multicollinearity.

1. **Box‑Cox‑scaled stress** – `stress_bc = boxcox(axial_stress_kn_per_cm2, λ=0.2)` (reduces skewness and decorrelates from raw stress).  
2. **Pressure‑humidity ratio** – `press_hum_ratio = line_pressure_kpa / (relative_humidity_pct + 1)`.  
3. **Temperature‑adjusted stress** – `temp_adj_stress = axial_stress_kn_per_cm2 * (1 + ambient_temperature_c/100)`.  
4. **Unified coolant flow (log‑scaled)** – `log_coolant_flow = np.log(coolant_flow_l_min + coolant_flow_gal_min * 3.785 + 1)`.  
5. **Target‑encoded categorical groups** – one‑hot‑free encodings for `operator_shift`, `site_region`, and `sensor_vendor` using leave‑one‑out mean of the deformation index.  

**Justification:** The assessment shows that a few engineered interactions dominate predictive power but suffer from severe multicollinearity and many raw variables contribute negligible signal. The proposed features retain the strong physics relationships (stress, pressure, temperature, flow) while applying variance‑stabilising transforms and new ratios that are less correlated with existing terms. Target‑encoding the low‑signal categorical columns adds useful information without inflating dimensionality, giving the coder a concrete additive request that can improve model stability and overall RMSE.
